# Python Income & Advertising Data Analysis

## 📊 Overview

This project demonstrates data analysis and visualization using Python in Google Colab.

Two datasets were analyzed:

* **Income Dataset**
* **Advertising Dataset**

The project focuses on loading datasets, exploring the data, performing basic statistical analysis, checking for missing values, and creating meaningful visualizations.

## 📁 Datasets

### 1. Income Dataset

The Income dataset contains information about:

* Age
* Education
* Experience
* Income

### 2. Advertising Dataset

The Advertising dataset contains information about:

* TV advertising
* Radio advertising
* Newspaper advertising
* Sales

## 🔍 Data Analysis

The following operations were performed on both datasets:

* Dataset loading using Pandas
* Viewing the first few records using `head()`
* Understanding dataset structure using `info()`
* Statistical analysis using `describe()`
* Checking for missing values using `isnull().sum()`
* Correlation analysis

## 📈 Visualizations

### Income Dataset

The following graphs were created:

* Age vs Income
* Education vs Income
* Experience vs Income
* Income Distribution
* Income Boxplot
* Income Correlation Heatmap

### Advertising Dataset

The following graphs were created:

* TV Advertising vs Sales
* Radio Advertising vs Sales
* Newspaper Advertising vs Sales
* Sales Distribution
* Advertising Data Boxplot
* Advertising Correlation Heatmap

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Seaborn**

The objective of this project is to gain practical experience in data loading, data exploration, basic statistical analysis, and data visualization using Python.
